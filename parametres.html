Ces paramètres s'appliquent à l'ensemble du logiciel : structure des frais disponible lors des encaissements, modes de paiement proposés, et seuils utilisés pour générer les alertes affichées dans le tableau de bord et la cloche de notifications.

Transfert des Données (vers une autre machine)

Exportez toutes les données du logiciel dans un seul fichier, puis importez ce fichier sur un autre poste pour retrouver exactement les mêmes données (élèves, paiements, RH, notes, documents, paramètres...).

Zone de Danger

Efface définitivement toutes les données actuellement enregistrées sur cette machine (élèves, paiements, personnel, etc.) pour repartir sur une base totalement vierge.
